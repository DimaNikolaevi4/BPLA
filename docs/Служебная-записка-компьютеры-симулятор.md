# Служебная записка: компьютеры для симулятора БПЛА

> **Черновик от 19.11.2026.** Готовится для установки симулятора на занятиях кружка «Основы управления БПЛА».
> Заполнить: количество машин, инвентарные номера и данные остальных ПК (раздел 4), подпись и дату.

## 1. Основание

- Рабочая программа кружка «Основы управления БПЛА» (72 ч, 2026/2027 уч. год), занятия — вторник и четверг, 4 пара.
- Отработка полётов без риска для техники и обучающихся — на симуляторе.

## 2. Программное обеспечение

**«Академия дронов: Медвежий патруль»** — общедоступный симулятор управления беспилотниками
(проект «Берлога», Ассоциация участников технологических кружков). Распространяется бесплатно.

- Ссылка для скачивания: <https://vkplay.ru/play/game/akademija_dronov_medvezhij_patrul/>
- Альтернативный источник: <https://platform.kruzhok.org/academy/drones#download>
- Платформа: Windows 10/11 (64 бит) или Linux 20.04. Установка — распаковка архива, запуск `DroneAcademy.exe`, лицензионное соглашение.

## 3. Системные требования

По официальной инструкции разработчика (версия 1.0):

| Параметр | Минимальные | Рекомендуемые |
|---|---|---|
| ОС | Windows 10 (64 бит) / Linux 20.04 | Windows 10 (64 бит) / Linux 20.04 |
| Процессор | AMD Ryzen 5500 / Intel Core i5-13500H | AMD Ryzen 5600 / Intel Core i5-13600K |
| Оперативная память | 8 ГБ | 16 ГБ |
| Место на диске | 2 ГБ | 4 ГБ |
| Видеокарта | Radeon RX Vega 7 / Intel Iris Xe Graphics G7 / Nvidia GeForce MX250 | Nvidia GeForce RTX 3050 6 ГБ |
| Разрешение экрана | 1280×720 | 1920×1080 |
| Управление | клавиатура + мышь | геймпад Zorro Radio Controller (M2) / Sony DualShock 4 |

Для сведения, страница игры в Steam указывает более мягкий минимум: Windows 10/11, Intel Core i3-8130U (2,20 ГГц), 6 ГБ ОЗУ, встроенная видеокарта, 500 МБ на диске.

## 5. Требования к новой машине

| Компонент | Рекомендуемая конфигурация |
|---|---|
| Процессор | Intel Core i5-12400 / AMD Ryzen 5 5600 (6 ядер, от 2,5 ГГц) |
| Оперативная память | 16 ГБ DDR4 (2×8 ГБ, двухканальный режим) |
| Видеокарта | NVIDIA GeForce RTX 3050 6 ГБ (допустимо — GTX 1660 Super 6 ГБ; минимум — Intel Iris Xe) |
| Накопитель | SSD NVMe 512 ГБ |
| ОС | Windows 10 Pro / Windows 11 Pro, 64 бит |
| Монитор | 24″, 1920×1080 |
| Периферия | клавиатура, мышь; геймпад DualShock 4 — по возможности |
