## 1. Основание

- Рабочая программа кружка «Основы управления БПЛА» (72 ч, 2026/2027 уч. год), занятия — вторник и четверг, 4 пара.

## 2. Программное обеспечение

**«Академия дронов: Медвежий патруль»** — общедоступный симулятор управления беспилотниками
(проект «Берлога», Ассоциация участников технологических кружков). Распространяется бесплатно.

- Ссылка для скачивания: <https://vkplay.ru/play/game/akademija_dronov_medvezhij_patrul/>
- Альтернативный источник: <https://platform.kruzhok.org/academy/drones#download>
- Платформа: Windows 10/11 (64 бит) или Linux 20.04. Установка — распаковка архива, запуск `DroneAcademy.exe`, лицензионное соглашение.

**Примечания по ПК № 1 (кабинет 43, данные сняты 19.11.2026):**

- Моноблок MSI Wind Top AP1920 (по наклейке — AP1920-XXXRU, по системе — MS-A912), имя в сети `43-З-ПК`, серийный номер `MSA912AAS0110827`.
- **Инвентарный номер не установлен.** В отчёте указан только серийный номер — это разные вещи; инв. № берём из журнала учёта имущества или шильдика и вписываем в графу. Серийный номер подставлять нельзя.
- Год 2010 — ориентир по дате BIOS (18.08.2010); уточнить по паспорту/журналу.
- Экран 18,5″, 1366×768: выше минимума 1280×720, но ниже рекомендуемых 1920×1080.
- Расхождение лицензии: на корпусе наклейка Windows 7 Starter, установлена Windows 7 Ultimate SP1 — зафиксировать при приёмке.
- Модернизация нецелесообразна: процессор Atom D510, потолок ОЗУ 4 ГБ, замена HDD на SSD не компенсирует слабый CPU. По этой машине речь идёт о замене, а не об апгрейде.

**Как оценивать соответствие:** ниже мягкого минимума (Intel Core i3-8130U, 6 ГБ ОЗУ, встроенная графика) симулятор не потянет; комфортная работа — от i5-13500H, 8 ГБ, видеокарта уровня Intel Iris Xe / Radeon RX Vega 7 / GeForce MX250. В графе «Соответствие» ставить один из кодов:

- **Г** — годен, комфортный уровень;
- **М** — годен на минимуме (i3-8130U / 6 ГБ, встроенная графика), без запаса;
- **Н** — не годен, обязательно указать, что именно не проходит: `Н (процессор)`, `Н (ОЗУ)`, `Н (видеокарта)`, `Н (ОС 32 бит)`, `Н (ОС Windows 7 — не поддерживается)`;
- **?** — данных нет/машина не проверена.

В графе «Симулятор запускается» — «да», «нет (причина)» или «не проверялся».
