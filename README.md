# БПЛА — кружок «Основы управления БПЛА»

**Идея:** внеурочный технический кружок для студентов техникума — от устройства дрона и правил безопасности до сборки, настройки и первых полётов. Программа рассчитана на 72 часа за учебный год.

- Учреждение: ГБПОУ РО «Сальский индустриальный техникум» (г. Сальск)
- Руководитель: Бардаков Д.Н.
- Учебный год: 2026–2027
- Занятия: вторник и четверг, 4 пара (13:45–15:30)

## Что реализовано

Организационная часть кружка закрыта полностью — есть все документы, которые требует учебная часть:

| Файл | Что это | Состояние |
|---|---|---|
| `Программа БПЛА .docx` | рабочая программа кружка, 72 часа | ✅ готова |
| `ГРАФИК РАБОТЫ.docx` | график занятий на 2026–2027 | ✅ готов |
| `Список.docx` | список членов кружка | ✅ есть |
| `Журнал кружка БПЛА 2026-2027 I полугодие.doc` | журнал работы и посещения, сентябрь–декабрь 2026 (единственный формат; .docx и .xlsx удалены как дубли) | ✅ готов |
| `кружок/` | дополнительные материалы: доп. образовательная программа, журнал кружковой работы, программы кружка WEB-программирование, «Обладание своим web», ВПК «Витязь» | 📚 архив |

## Статус

- **I полугодие 2026/2027:** документы готовы, журнал заполняется.
- **II полугодие:** журнал и отчётность ещё не заведены — это следующий шаг (по аналогии с I полугодием).
- Материалы занятий (презентации, инструкции по полётам) в репозитории пока не выделены в отдельную папку.
- В общем календаре задач репозиторий участвует с 18.11.2026: `plan.json` есть.
- Готовится служебная записка на компьютеры для симулятора «Академия дронов: Медвежий патруль» — черновик в `docs/Служебная-записка-компьютеры-симулятор.md` (требования, данные ПК, конфигурация новой машины).
